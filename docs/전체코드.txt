## src/main.ts

경로: D:/be/study/movie/src/main.ts

설명: Nest 앱 생성 → CORS 적용 → 3000 포트 실행 순서입니다.

````typescript
import 'reflect-metadata';
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module.js';
import { configureCors } from './cors.js';

async function bootstrap(): Promise<void> {
  const app = await NestFactory.create(AppModule);

  // 기본 실행은 CORS를 켭니다. --no-cors는 워크북의 설정 전/후 비교용입니다.
  configureCors(app, !process.argv.includes('--no-cors'));
  app.enableShutdownHooks();

  const port = Number(process.env.PORT ?? 3000);
  await app.listen(port, 'localhost');
  console.log(`영화 평점 API: http://localhost:${port}`);
}

bootstrap().catch((error: unknown) => {
  console.error('서버를 실행하지 못했습니다.', error);
  process.exitCode = 1;
});
````

````typescript
  if (enabled) {
    // 브라우저가 이 출처의 화면에서 API 응답을 읽을 수 있도록 허용합니다.
````

````typescript
import { Module } from '@nestjs/common';
import { ConfigModule, ConfigService } from '@nestjs/config';
import { TypeOrmModule } from '@nestjs/typeorm';
import { Member } from './entity/member.entity.js';
import { Rating } from './entity/rating.entity.js';
import { MemberController } from './controller/member.controller.js';
import { RatingController } from './controller/rating.controller.js';
import { MemberService } from './service/member.service.js';
import { RatingService } from './service/rating.service.js';

@Module({
  imports: [
    // movie/.env의 값을 읽고 다른 클래스에서도 사용할 수 있게 합니다.
    ConfigModule.forRoot({ isGlobal: true }),
    TypeOrmModule.forRootAsync({
      inject: [ConfigService],
      useFactory: (config: ConfigService) => ({
        type: 'mysql' as const,
        host: config.getOrThrow<string>('DB_HOST'),
        port: Number(config.get<string>('DB_PORT', '3306')),
        username: config.getOrThrow<string>('DB_USER'),
        password: config.getOrThrow<string>('DB_PASSWORD'),
        database: config.getOrThrow<string>('DB_NAME'),
        autoLoadEntities: true,
        // 테이블은 sql/schema.sql로 만듭니다. 실행 때 자동 변경하지 않습니다.
        synchronize: false,
        charset: 'utf8mb4',
        timezone: 'Z',
        supportBigNumbers: true,
        bigNumberStrings: false,
        retryAttempts: 1,
      }),
    }),
    // 이 등록으로 Repository<Member>, Repository<Rating>을 주입할 수 있습니다.
    TypeOrmModule.forFeature([Member, Rating]),
  ],
  controllers: [MemberController, RatingController],
  providers: [MemberService, RatingService],
})
export class AppModule {}
````

````typescript
import { Column, Entity, JoinColumn, ManyToOne, PrimaryGeneratedColumn, Unique } from 'typeorm';
import { BaseTimeEntity } from './base-time.entity.js';
import { Member } from './member.entity.js';

@Entity('rating')
@Unique('uk_rating_member_movie', ['member', 'movieId'])
export class Rating extends BaseTimeEntity {
  @PrimaryGeneratedColumn({ name: 'rating_id', type: 'bigint' })
  ratingId!: number;

  // 여러 평점이 한 회원에 속합니다. member_id가 실제 외래키입니다.
  @ManyToOne(() => Member, { nullable: false })

  @Column({ name: 'movie_id', type: 'bigint' })
  movieId!: number;

  @Column({ type: 'tinyint' })
  score!: number;

  @Column({ type: 'text', nullable: true })
  comment!: string | null;
````

## src/service/member.service.ts

경로: D:/be/study/movie/src/service/member.service.ts

설명: exists()로 DB에 값이 있는지 확인하고 available로 바꿉니다.

````typescript
import { Injectable } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Member } from '../entity/member.entity.js';
import type { CheckResponseDto } from '../dto/check-response.dto.js';

@Injectable()
export class MemberService {
  constructor(
    @InjectRepository(Member)
    private readonly memberRepository: Repository<Member>,
  ) {}

  async checkNickname(nickname: string): Promise<CheckResponseDto> {
    const exists = await this.memberRepository.exists({ where: { nickname } });
    // 이미 존재하면 사용 불가(false), 존재하지 않으면 사용 가능(true)입니다.
    return { available: !exists };
  }

  async checkEmail(email: string): Promise<CheckResponseDto> {
    const exists = await this.memberRepository.exists({ where: { email } });
    return { available: !exists };
  }
}
````

## src/service/rating.service.ts

경로: D:/be/study/movie/src/service/rating.service.ts

설명: 회원 존재 확인 후 해당 회원의 평점을 최신순으로 반환합니다.

````typescript
import { Injectable, NotFoundException } from '@nestjs/common';
import { InjectRepository } from '@nestjs/typeorm';
import { Repository } from 'typeorm';
import { Rating } from '../entity/rating.entity.js';
import { Member } from '../entity/member.entity.js';
import { RatingResponseDto } from '../dto/rating-response.dto.js';

@Injectable()
export class RatingService {
  constructor(
    @InjectRepository(Rating)
    private readonly ratingRepository: Repository<Rating>,
    //회원이 있는지 검사해야하기 ㅇ때문에 연결해줌
    @InjectRepository(Member)
    private readonly memberRepositoty: Repository<Member>,
  ) {}
  async getRatingsByMember(memberId: number): Promise<RatingResponseDto[]> {
    const exists = await this.memberRepositoty.exists({ where: { memberId } });
    if (!exists) {
      throw new NotFoundException('존재하지 않는 유저입니다.');
    }

    const ratings = await this.ratingRepository.find({
      where: { member: { memberId } },
      order: { ratingId: 'DESC' },
    });

    return ratings.map(RatingResponseDto.from);
  }
}
````

````markdown
# Repository 사용 방식

별도 Repository 클래스 대신 TypeORM의 기본 `Repository<T>`를 사용합니다.

`AppModule`에서 `TypeOrmModule.forFeature([Member, Rating])`로 등록하고,
서비스 생성자에서 `@InjectRepository(Member)` 또는 `@InjectRepository(Rating)`으로 주입받습니다.

`MemberService`는 `exists()`로 중복 여부를 확인하고, `RatingService`는 회원 존재 여부를 확인한 뒤 `find()`로 해당 회원의 평점을 최신순으로 조회합니다.
````

````sql
-- IF NOT EXISTS로 이미 있는 테이블과 데이터를 보존합니다.
CREATE TABLE IF NOT EXISTS member (
    member_id BIGINT AUTO_INCREMENT PRIMARY KEY,
    email VARCHAR(254) NOT NULL UNIQUE,
    password VARCHAR(60) NOT NULL,
    nickname VARCHAR(50) NOT NULL UNIQUE,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS rating (
    rating_id BIGINT AUTO_INCREMENT PRIMARY KEY,
    member_id BIGINT NOT NULL,
    movie_id BIGINT NOT NULL,
    score TINYINT NOT NULL,
    comment TEXT,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (member_id) REFERENCES member(member_id),
    UNIQUE KEY uk_rating_member_movie (member_id, movie_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 8주차 준비용 테이블만 생성합니다. 이번 주에는 엔티티와 API를 만들지 않습니다.
CREATE TABLE IF NOT EXISTS favorite (

    movie_id BIGINT NOT NULL,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (member_id) REFERENCES member(member_id),
    UNIQUE KEY uk_favorite_member_movie (member_id, movie_id)
````

````javascript
    port: Number(process.env.DB_PORT ?? 3306),
    user: process.env.DB_USER,
    password: process.env.DB_PASSWORD,
    charset: 'utf8mb4',
    timezone: 'Z',
    // 직접 작성한 SQL 파일 실행에만 다중 문장을 허용합니다.
    multipleStatements: true,
  });
  const database = mysql.escapeId(process.env.DB_NAME);
  await connection.query(`CREATE DATABASE IF NOT EXISTS ${database} CHARACTER SET utf8mb4`);
  await connection.query(`USE ${database}`);
  await connection.query("SET time_zone = '+00:00'");
  await connection.query(await readFile(new URL('../sql/schema.sql', import.meta.url), 'utf8'));
  await connection.beginTransaction();
  await connection.query(await readFile(new URL('../sql/seed.sql', import.meta.url), 'utf8'));
  await connection.commit();
  const [members] = await connection.query('SELECT member_id, nickname FROM member ORDER BY member_id');
  console.log('테이블 및 시드 준비 완료. 평점 조회에 사용할 회원 번호:');
  console.table(members);
} catch (error) {
  if (connection) await connection.rollback();
  console.error('DB 초기화 실패:', error.code ?? error.message);
  process.exitCode = 1;
} finally {
  if (connection) await connection.end();
}
````

## mock-frontend/server.mjs

경로: D:/be/study/movie/mock-frontend/server.mjs

설명: Node 내장 HTTP 기능으로 간이 화면을 5173 포트에서 제공합니다.

````javascript
import { createServer } from 'node:http';
import { readFile } from 'node:fs/promises';

// 외부 패키지 없이 index.html만 제공하는 로컬 정적 서버입니다.
const files = {
  '/': ['index.html', 'text/html; charset=utf-8'],
};

const server = createServer(async (request, response) => {
  const path = new URL(request.url, 'http://localhost:5173').pathname;
  const file = files[path];
  if (!file || !['GET', 'HEAD'].includes(request.method)) {
    response.writeHead(404).end('Not found');
    return;
  }
  try {
    const body = await readFile(new URL(file[0], import.meta.url));
    response.writeHead(200, { 'Content-Type': file[1], 'Cache-Control': 'no-store' });
    response.end(request.method === 'HEAD' ? undefined : body);
  } catch {
    response.writeHead(500).end('Cannot read frontend file');
  }
});

server.listen(5173, 'localhost', () => console.log('간이 프론트: http://localhost:5173'));
````

````markdown
## 4. 파일이 서로 연결되는 원리

```text
브라우저 mock-frontend/index.html의 script
 → HTTP GET 요청
 → Controller: URL의 값을 받음
 → Service: 회원 존재 여부 확인, 조회 조건 설정
 → TypeORM Repository: MySQL에 SQL 실행
 → DTO: 필요한 필드만 선택
 → JSON 응답
 → 화면에 JSON 응답 그대로 표시
```

- `MemberController`는 닉네임과 이메일 경로를 담당합니다.
- `MemberService`는 DB에 값이 있는지 `exists()`로 확인하고 결과를 반대로 뒤집습니다. 존재하면 `available: false`입니다.
- `RatingService`는 회원부터 확인합니다. 회원이 없으면 404, 있으면 그 회원의 평점만 최신순으로 조회합니다.
- `RatingResponseDto.from()`은 평점의 6개 필드만 골라 반환합니다. 회원 비밀번호나 내부 관계 객체는 응답하지 않습니다.
- `Member`와 `Rating`은 공통 날짜 클래스를 상속합니다. 날짜는 JSON으로 변환할 때 ISO 8601 문자열이 됩니다.
- `movieId`는 TMDB의 식별 번호를 담는 일반 컬럼입니다. 이번 화면에서는 JSON의 영화 번호를 그대로 표시하며 TMDB 호출/API Key는 필요 없습니다.
- DB의 날짜는 초기화 시 UTC로 기록하고, 응답은 `Z`가 붙는 UTC 시간입니다. 간이 화면은 JSON 응답을 그대로 표시합니다.
- SQL의 BIGINT ID를 API 명세에 맞춰 number로 반환합니다. 이 학습용 구현은 JavaScript 안전 정수 범위 안의 ID를 전제로 합니다.
- `repository` 폴더에 별도 클래스가 없는 이유는 NestJS에서 TypeORM의 기본 `Repository<T>`를 주입받기 때문입니다.
- `.ts` 코드의 내부 import 경로 끝에 `.js`가 붙은 것은 이 프로젝트가 ESM 방식이며 컴파일 후 실행 파일이 `.js`가 되기 때문입니다.
- 클래스 필드의 `!`는 TypeORM이 DB에서 값을 채운다는 것을 TypeScript에 알려주는 문법입니다.

## 6. CORS 설정 전/후 실습

1. 실행 중인 백엔드 터미널에서 `Ctrl+C`를 누릅니다.
2. 아래 명령으로 CORS를 끈 백엔드를 실행합니다.

```powershell
npm.cmd run build
npm.cmd run start:no-cors
```

3. `http://localhost:5173`에서 F12 → Console을 열고 중복 확인 버튼을 누릅니다.
4. CORS 오류와 화면의 연결 실패 안내를 캡처합니다.
5. 백엔드를 `Ctrl+C`로 종료하고 `npm.cmd start`로 다시 실행합니다.
6. 같은 버튼을 누르면 정상 응답합니다. 다른 터미널의 프론트 서버는 계속 실행해 두면 됩니다.

기본 CORS 설정은 `src/cors.ts`에 있으며 `main.ts`에서 적용합니다.
허용 출처는 정확히 `http://localhost:5173`입니다. `127.0.0.1:5173`은 다른 출처입니다.
단순 GET은 서버가 처리해도 브라우저가 응답 읽기를 막을 수 있습니다.
Preflight가 필요한 요청은 사전 OPTIONS 요청이 실패하면 실제 요청이 전송되지 않을 수도 있습니다.
Postman과 Node의 fetch는 브라우저 CORS 정책을 적용하지 않으므로 브라우저 확인도 별도로 필요합니다.

## 9. 자주 생기는 문제

| 증상 | 확인할 것 |
| --- | --- |
| `ER_ACCESS_DENIED_ERROR` | 실제 `movie/.env`의 사용자·비밀번호, 저장 여부. `.env.example`만 수정하지 않았는지 확인 |

| 테이블이 없다는 오류 | `npm.cmd run db:init` 실행 |
| `EADDRINUSE` | 3000 또는 5173을 사용 중인 기존 개발 서버 종료 |
| 화면에서 연결 실패 | 백엔드 실행 상태, 접속 주소가 `localhost:5173`인지, CORS 모드 확인 |
| `npm.ps1` 실행 정책 오류 | 가이드처럼 `npm.cmd`로 실행 |
| `EBADENGINE` 경고 | 위 Node.js 지원 버전 확인 |

서버 포트를 변경한다면 `.env`의 `PORT`, `mock-frontend/index.html`의 `API_BASE`, Postman의 `baseUrl`을 함께 변경하세요.
````
